# Publishing this layout as a Notion template (checklist)

Sources: https://www.notion.com/help/selling-on-marketplace · https://www.notion.com/help/template-gallery-guidelines-and-terms · https://www.notion.com/help/duplicate-public-pages

- [ ] Build the template as a **standalone page** (not a database sub-page) with the three databases inside it.
- [ ] Add a "Start here" callout with instructions and placeholder content (guideline: user experience).
- [ ] Use only synthetic content (this pack's garden/recipe/reading data). No real names, accounts or links to private pages.
- [ ] Check every link points inside the template (duplicators cannot open outside pages).
- [ ] Share → Publish → toggle **Duplicate as template**.
- [ ] Creator profile at app.notion.com/profile (your account).
- [ ] Marketplace → Start a new template: name, link, category, language, 3-5 accurate screenshots.
- [ ] Free listing first; paid requires Stripe review (can take months) or a third-party payment link.
- [ ] Name/imagery follow Notion brand guidelines; no "Notion" in the template name.
